Chave da API do YouTube

Como criar a chave (grátis, ~2 min)
  1. Abra console.cloud.google.com e entre com sua conta Google. Crie um projeto (ex.: Prospecta).
  2. Abra a YouTube Data API v3 e toque em Ativar.
  3. Vá em Credenciais → Criar credenciais → Chave de API. Copie e cole aqui.
  4. Recomendado: em “Restrições de aplicativo” escolha Sites e adicione . Em “Restrições de API” escolha só a YouTube Data API v3.

A cota grátis é de 10.000 unidades por dia. Cada página de busca gasta ~100–110 (≈ 50 vídeos analisados). Ela renova à meia-noite do horário do Pacífico (≈ 5h em Brasília).

Como enviar os e-mails

Como configurar o envio automático (uma vez só)
  1. No mesmo projeto do Google Cloud, ative a Gmail API.
  2. Abra a Google Auth Platform (tela de permissão OAuth) → Começar. Nome do app: Prospecta. Público: Externo. Coloque seu e-mail.
  3. Em Público-alvo → Usuários de teste, adicione o seu Gmail.
  4. Em Clientes → Criar cliente → tipo Aplicativo da Web.
    Origens JavaScript autorizadas:
    URIs de redirecionamento autorizados:
  5. Copie o ID do cliente, cole acima e toque em Conectar Gmail. Se aparecer “O Google não verificou este app”, toque em Avançado → Acessar (o app é seu).

O login dura 1 hora; depois o app pede para conectar de novo com um toque. O Gmail permite ~500 envios por dia — use intervalos para não cair no spam.
